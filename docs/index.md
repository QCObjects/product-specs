# QCObjects Product Specs

**Source of truth** for the QCObjects ecosystem: framework, SDK, CLI, resulting app
structure, templates, conventions, and the unified v3.0 vision.

Start with [Product Vision](01-product-vision.md), or browse the tabs above.
The full annotated index lives in the repository
[README](https://github.com/QCObjects/product-specs#qcobjects-product-specs).

> Specs 01–14 describe the **current** framework. Spec 15 describes **where it is
> going**. When they conflict, 15 governs and the affected spec MUST be updated
> in the same PR.
